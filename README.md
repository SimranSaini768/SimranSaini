# Projectile Motion Calculator

This is a simple program that helps the user calculate the area of different shapes like square, rectangle,cirle,triangle based on the input given by the user.The program runs till the user wants



# Features

1.Menu Driven Interface

2.Gives the option to calculate the different aspects of a projectile motion such as the time of flight, maximum height and range respectively. 

3. Takes velocity and angle of projection as inputs and calculates the required projectile motion parameters.

# Usage

1. When the program starts you see a menu:

```
WELCOME
please make a choice from the below listed options
1.Time of flight

2. Maximum Height

3. Range of projectile motion

```

2.Enter the number corresponding to the required calculation(1-3)

3. Enter the velocity of the object when prompted

4.Enter the angle of projection when prompted

5.The program calculates and displays the selected projectile motion parameter:



1 → Time of flight

2 → Maximum height

3 → Range of projectile motion

a. If you enter 'y' then the program runs again
b. If you enter 'n' then the program ends and prints "Thank You"
